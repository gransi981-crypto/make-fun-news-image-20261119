A one-page newspaper front page that sums up Thursday 19 November 2026's world news in a single image: the International Court of Justice ruling that Myanmar committed genocide against the Rohingya, the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, Iran widening its Gulf strikes as the US Senate rejects a war-powers curb, the EU's €45bn loan proposal for Ukraine, Israel crossing the Gaza ceasefire line, Anthropic's record ~$2 trillion Nasdaq debut, and Voyager 1 reaching one light-day from Earth — plus the day's other stories in a ticker. The image is drawn at build time by `render.py` (Pillow) from same-day reporting; the graded program `main.py` only copies the finished PNG to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
